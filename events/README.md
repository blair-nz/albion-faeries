# Event minisite template

Copy `events/iya-luv-2026/` when starting a new gathering call site.

1. Duplicate the folder to `events/<slug>-<year>/` (year in the URL)
2. Put the year in `<title>` and the visible H1
3. Keep `css/event.css` linked
4. Replace hero meta, sections, and contact CTAs
5. Add the call PDF under `assets/archive/calls/` and link it from the hero + `/gatherings/archive`
6. Link the event from `whats-on.html` and optionally `index.html`

Iya Luv source materials: Notion https://iyaluv.notion.site/ and the PDF call (large; linked from WordPress until a compressed copy is added).
