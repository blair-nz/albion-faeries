GitHub, staging, and the live hearth

One private repo. Push staging to try the hearth. Merge to main for albionfaeries.org.uk. Staging keeps its own Circles database.

How to read it

The moss box is staging: staging.albionfaeries.org.uk. Try copy, layout, and Circles there. It does not share the live database, so a test note cannot land on the public hearth.

The gold box is live: albionfaeries.org.uk. It updates only when staging is merged into main. Do not push feature work straight to main.

Local npm run dev is a third hearth on your laptop. It is not staging and not live. Keep .dev.vars on the machine.

Blair invites Tech Circle GitHub accounts as collaborators on the private repo. When the Circle is happy with staging, open a pull request from staging into main.
